# Vocabulary construction and retrieval

The static V1 list is the original 30-entry configuration, preserved verbatim as structured data. The expanded `configs/religious_lexicon.tsv` starts with those terms and adds biblical names, places, books, theology, denominations, practices and specialized terms. Biblical names and themes draw on the [King James Bible, Project Gutenberg edition](https://www.gutenberg.org/ebooks/10), identified as public domain in the United States. Denominational and specialized names are ordinary terms, with project-authored short descriptions and aliases in the context column. The file contains no copied modern dictionary definitions or sermon excerpts.

Normalization applies Unicode NFKC, case folding and English word tokenization. Preserve original casing for Whisper hints. For scoring, prefer the longest term at the same position and align term occurrences against each reference independently. The entire expanded lexicon is fixed across evaluation conditions.

Retrieval reads only church name, sermon title, description, scripture reference and speaker. Exact matching uses contiguous normalized terms. TF-IDF uses unigrams and bigrams over the curated entry and its context. Semantic retrieval uses a revision-pinned local [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) snapshot (Apache 2.0), mask-aware mean pooling and cosine similarity. Hybrid ranking adds exact-match, TF-IDF and nonnegative cosine scores. Generic or empty topic metadata falls back to the original list. Retrieval never reads audio, candidate transcripts or pseudo-reference transcripts.

Hints are packed in rank order by whole term using the actual installed Whisper tokenizer. The common hotword cap is 96 tokens. The CTranslate2 wrapper uses a 448-token decoder context for the inspected Whisper models, and faster-whisper trims hotwords to 223 tokens. It suppresses hotwords when a prefix is supplied. The implementation verifies both the native cap and total first-window prompt length. Saved predictions include actual token counts and dropped-term status.
